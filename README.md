# Swapnajit Das — academic website

## Preview
Open index.html in a browser. Keep all website files together.

## Publish on GitHub Pages
1. Create a public repository named swapnajit2.github.io under Swapnajit2.
2. On its Code page, select Add file > Upload files.
3. Upload the seven HTML files, style.css, portrait.jpg, both PDF files, and this README.md directly into the repository (not inside a folder).
4. Commit the upload.
5. Open Settings > Pages. Under Source select Deploy from a branch.
6. Select main and /(root), then Save.
7. Once deployment finishes, visit https://swapnajit2.github.io/.

## Editing
Edit the relevant HTML file on GitHub, then commit your changes. Shared colours and layout are in style.css. No installation or coding tools are needed.

The site currently contains Home, Research, Papers & Preprints, Talks, Teaching, Education, and Contact. Your photograph is included. A CV and lecture notes can be added when supplied.

## Add slides or lecture notes for a talk
Upload the PDF to a folder called talks in your GitHub repository. In talks.html, add a link beneath the relevant talk, for example: <a href="talks/hurewicz-slides.pdf">Slides (PDF)</a>. Match the filename exactly. Links are only shown when the corresponding file exists.
